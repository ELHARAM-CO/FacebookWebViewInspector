# Facebook WebView Inspector

مشروع Android مستقل لتشخيص عناصر Like / Reply داخل Facebook WebView.

## الوظائف
- فتح Facebook داخل WebView مع JavaScript وDOM storage.
- فحص العناصر المطابقة لمسميات عربية وإنجليزية متعددة.
- عرض النص، aria-label، role، قابلية التفاعل، والموقع التقريبي.
- زر Like رئيسي ينفذ Like فعليًا ويكرر المحاولة وفق الفاصل الزمني المحدد حتى الضغط على إيقاف.
- لا يحاول تجاوز CAPTCHA أو التحقق من أن المستخدم إنسان.

## الاستخدام
1. افتح التطبيق وسجّل الدخول إلى Facebook داخل WebView.
2. انتقل يدويًا إلى المنشور/التعليقات المطلوبة.
3. اضغط "Like" لبدء التنفيذ المتكرر وفق الفاصل الزمني.
4. اضغط "إيقاف" لإنهاء التكرار.

> ملاحظة: اختبار Like قد يغيّر حالة الإعجاب فعليًا، لأنه ينفذ click على عنصر Facebook الحقيقي. لا يتم نشر تعليق أو إرسال نص Reply تلقائيًا.

## البناء
افتح المشروع في Android Studio ثم Sync/Build APK. لم يتم تضمين Gradle wrapper لأن بيئة التنفيذ الحالية لا تحتوي Gradle.
